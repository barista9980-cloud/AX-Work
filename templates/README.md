# Asset Management Master Template Storage

본 디렉터리는 **(주)폭스커넥트 및 범용 자산 관리 표준 프레임워크**의 마스터 서식 템플릿 문서 모음입니다.

- `Master_Corporate_Contract_Note_Overhead_Template.md`: 부동산, 법인차량, 기업보험 3대 자산 통합 워드 계약관리노트(.docx) 최상위 마스터 규격서
- `Master_Corporate_Asset_Register_Template.md`: 2단계 표 분리 및 동적 타임스탬프가 반영된 엑셀 총괄자산대장(.xlsx) 마스터 규격서 (SSOT)
- `External_Audit_IPO_Asset_Register_Template.md`: 회계법인 외부감사 및 IPO 제출용 재무 검증 뷰 추출 규격서
- `Corporate_Real_Estate_Contract_Note_Template.md`: 부동산 계약관리노트 개별 템플릿
- `Corporate_Vehicle_Contract_Note_Template.md`: 법인차량 계약관리노트 개별 템플릿
- `Corporate_Insurance_Contract_Note_Template.md`: 기업보험 계약관리노트 개별 템플릿
