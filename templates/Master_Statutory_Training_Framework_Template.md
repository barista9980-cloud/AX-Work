# 📜 범용 법정의무교육 통합 이수 및 독려 파이프라인 마스터 표준 (Universal Statutory Training Framework)

> **Document Identity**: 본 표준 서식은 특정 그룹웨어(아마란스, 하이웍스, 네이버웍스, 카카오워크, Google Workspace 등)에 종속되지 않은 **글로벌 기업 범용 법정의무교육 마스터 마이크로 프레임워크(Universal Master Standard)**입니다.

## 1. 🎯 범용 법정의무교육 5대 필수 교육과정 체계
1. **직장 내 성희롱 예방교육** (남녀고용평등법 제13조 / 연 1회, 1시간 이상)
2. **장애인 인식개선교육** (장애인고용촉진법 제5조의2 / 연 1회, 1시간 이상)
3. **개인정보 보호교육** (개인정보보호법 제28조 / 연 1회 이상)
4. **직장 내 괴롭힘 예방교육** (근로기준법 제93조 / 연 1회 이상)
5. **산업안전보건교육 및 퇴직연금 / 기타교육** (산업안전보건법 제29조 등)

## 3. ✉️ 그룹웨어 독립적 이수 독려 메일 연동 제안 표준 (Extensible Mail Dispatch Architecture)

다양한 법인 및 그룹웨어 환경에 맞춰 적용할 수 있는 4가지 유연한 이수 독려 옵션:

### 🔹 옵션 A. 그룹웨어 Open API 연동 방식 (Direct REST API)
- **적용 대상**: 더존 아마란스 10, 네이버웍스, 카카오워크 등 오픈 API를 지원하는 사내 그룹웨어
- **특징**: `Authorization Bearer Token` 및 시그니처 연동으로 1:1 개인화 메일/알림톡 자동 발송

### 🔹 옵션 B. 범용 메일 서버 SMTP 연동 방식 (Universal SMTP Dispatch)
- **적용 대상**: 기업 자체 메일 서버, Exchange, Google Workspace, MS 365
- **특징**: SMTP(Port 587/465) 접속으로 미이수자 대상 1:1 맞춤형 HTML 독려 메일 직발송

### 🔹 옵션 C. 수신자 주소 & 텍스트 묶음 추출 방식 (Manual Copy-Paste / BCC)
- **적용 대상**: 외부 API/SMTP 접속이 제한된 타 법인 그룹웨어
- **특징**: 1초 만에 미이수자 사내 메일 주소 묶음(`;` 또는 `,` 구분자) 및 본문 템플릿을 추출하여 그룹웨어 작성창에 복사-붙여넣기 사용

### 🔹 옵션 D. 타 법인 담당자 전용 미이수자 리포트 분리 추출 (Export Report)
- **적용 대상**: 협력사, 계열사, 외주사 등 독립 관리 담당자가 존재하는 멀티 법인
- **특징**: 해당 법인 미이수자만 쏙 뽑아낸 독립 엑셀 리포트(`2026년도_OO법인_미이수자명단.xlsx`) 자동 분리 배포
