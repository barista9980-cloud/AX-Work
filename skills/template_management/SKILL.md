# 폭스커넥트 전사 템플릿 관리 & 능동 추천 표준운영절차 (SOP)

이 스킬은 폭스커넥트(FoxConnect)의 전사 업무([총무], [인사], [재무회계]) 진행 시 표준 문서 템플릿 관리, 능동적 템플릿 추천, 관리자 승인 절차 및 1:1 원본 클로닝 문서 생성을 규정합니다.

---

## 1. 📂 업무별 템플릿 저장소 구조 (`99_템플릿_양식`)

전사 각 부서 및 세부 업무별 공식 마스터 템플릿은 항상 각 도메인 폴더 맨 뒤의 **`99_템플릿_양식`** 전용 폴더에서 일괄 보관·관리합니다.

### 표준 경로 체계:
- **[총무]업무 전사 템플릿**: `G:\내 드라이브\[FoxConnect]\[총무]업무\99_템플릿_양식\`
- **[총무] 부동산 자산관리**: `G:\내 드라이브\[FoxConnect]\[총무]업무\01_부동산_자산관리\99_템플릿_양식\`
- **[인사]업무 전사 템플릿**: `G:\내 드라이브\[FoxConnect]\[인사]업무\99_템플릿_양식\`
- **[재무회계]업무 전사 템플릿**: `G:\내 드라이브\[FoxConnect]\[재무회계]업무\99_템플릿_양식\`

## 2. 🤖 능동적 템플릿 추천 프로토콜 (Proactive Recommendation)

사용자(관리자)가 문서 작성 또는 업무 진행을 요청할 때 AI는 아래 절차를 자동으로 수행합니다:

1. **자동 검색**: 요청된 업무 도메인의 `99_템플릿_양식` 폴더를 즉시 검색한다.
2. **능동적 제안**: 등록된 템플릿 양식이 존재할 경우, 사용자에게 먼저 안내하고 확인을 구한다.
   > *"현재 `99_템플릿_양식` 폴더에 등록된 [템플릿 파일명] 표준 양식이 있습니다. 해당 표준 양식을 1:1 복제하여 작성을 진행할까요?"*
3. **템플릿이 없을 경우**: 사용자에게 템플릿 신규 등록 여부를 문의하고, 관리자 승인 후 `99_템플릿_양식`에 정식 마스터 템플릿으로 등록한다.

## 3. 🎯 1:1 원본 클로닝 문서 생성 규칙 (Zero-Drift Cloning)

파이썬 스크립트를 사용하여 신규 Word(.docx) 문서를 자동 생성할 때, 폰트 자간, 테두리 픽셀, 셀 패딩 등의 미세한 시각적 오차(Layout Drift)를 0%로 방지하기 위해 다음 클로닝 메커니즘을 필수로 적용합니다:

```python
import shutil
import docx

# 1. 99_템플릿_양식 내 마스터 템플릿 1:1 완전 복제
shutil.copy2(master_template_path, target_output_path)

# 2. 복제된 파일 내부의 내용만 인플레이스(In-place) 갱신
doc = docx.Document(target_output_path)
# ... 내용 매핑 및 XML cantSplit 보장 ...
doc.save(target_output_path)
```

## 4. 📄 부동산 계약관리노트 7대 세부 작성 규정

`부동산_계약노트_표준양식.docx`를 사용하여 계약관리노트를 작성할 때 적용되는 7대 세부 규정:

1. **양식 1:1 클로닝**: `99_템플릿_양식\부동산_계약노트_표준양식.docx`를 1:1 원본 복제하여 작성.
2. **표준 4대 섹션**: 1. 계약 정보(5x4), 2. 수록 계약서 문서 목록(N건 5열), 3. 임대인 및 납부 계좌 정보(6x4), 4. 계약 변동 이력 및 특이사항(5x2).
3. **병합 셀 구조 보존**: 표 2 계좌번호(Col 1~3 병합), 비고(Col 0~3 병합), 표 3 기타 특약(Col 0~1 병합).
4. **라벨 vs 데이터 서식**: 
   - 라벨: `맑은 고딕`, `9.5pt`, `Bold=True`, `#1E293B`, `#F4F6F8` 배경, `Center` 정렬.
   - 데이터: `맑은 고딕`, `9.5pt`, `Bold=False`, `#0F172A`, `#FFFFFF` 배경, `Center` 정렬 (단, 1.2.3. 번호목록 및 파일명은 `Left` 정렬).
5. **셀 높이 동일화**: 표 3 `기타 특약 및 참조사항` 헤더 셀 높이 및 패딩을 표 2 `비고 (관리자 참고사항)` 셀과 100% 동일하게 매칭.
6. **실측 데이터 100% 반영**: OCR 및 임차료 정산 대장에서 파싱된 100% 검증 데이터만 수록.
7. **페이지 이월 & 레이아웃 통제**:
   - `cantSplit`: 모든 행에 `<w:cantSplit/>` 적용 (행 중간 잘림 방지).
   - `keep_with_next`: 모든 섹션 제목 단락에 `keep_with_next = True` 적용.
   - `tblHeader`: 표 0행에 `<w:tblHeader/>` 적용 (다음 장 헤더 자동 반복).
   - `vAlign = center`: 모든 셀에 OpenXML 세로 중앙 정렬 적용.
